**What is a bigram?** #anki
A bigram is a model that looks at the current character and gives you a list of probabilities for the next character, implemented as a matrix, which could be 27x27, so when you look up your current character by its index you get the row containing the probability of every other character, you can sample and then generate sequences from it.

**What is negative log likelihood** #anki
The goal is to answer: How can we know how bad a model is doing when generating data compared with the original data? For example in a bigram model for a given word we can easily get the probabilities for each word according to the model, then we could naively just make an average of probabilities, but then a very bad model could predict a little bit worse and the average would barely move, that's why average is not reliable, then a better alternative could be using a product because a low probability would rank lower and the signal of that mistake is stronger, then we run into another problem, if the sequence is too large the product collapses into 0, that's why we have to remember what operation turns a multiplication into a sum, that is log, so we calculate the log of each probability, sum the results and take the average, also since it is usual to see error as a positive number we sum the negative log, now the minimum is 0 and the error can be any positive number.
